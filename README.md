# tanya23

Небольшой статический сайт. Обычная главная страница раскрывает отдельные пространства: письмо, музыкальную пластинку и фотоальбом с видео.

**Сайт:** https://yorickyeng.github.io/tanya23/  
**Предпросмотр всех блоков:** https://yorickyeng.github.io/tanya23/?preview=all

## Локальный запуск

Установка зависимостей не нужна. Нужны Python 3 и, для проверок, Node.js 18+.

```sh
cd tanya23
npm run dev
```

Откройте http://127.0.0.1:4173/?preview=all. Обычный вид — адрес без параметров.

## Содержимое и время открытия

Редактируйте `content.json`. В `moments` находятся независимые блоки. У каждого есть `id`, `type`, `title`, `hint`, `opensAt` и `published`.

- Время задаётся полной датой с `+03:00`, например `2026-11-13T16:00:00+03:00`.
- `published: false` скрывает черновик и после дня рождения.
- Предпросмотр `?preview=all` показывает также черновики. Это инструмент подготовки, а не секретный или защищённый режим.
- Для проверки конкретного времени: `?preview=2026-11-13T15%3A59%3A00%2B03%3A00`.
- Главная перепроверяет расписание каждые 15 секунд и загружает обновлённый `content.json` каждые 30 секунд и при возвращении во вкладку.
- Уже открытый плеер или письмо не перестраиваются во время просмотра. Чтобы увидеть изменение такого виджета, обновите его страницу.
- После `archiveAt` на главной появятся ссылки на общий архив и повтор дня по времени.

## Письмо

В блоке `type: "letter"` замените `paragraphs`, `heading` и `signature`. Изначальный текст — редактируемый пример. Любое количество абзацев.

## Песня

1. Скопируйте свою запись в `assets/audio/song.mp3` (MP3 или совместимый M4A).
2. В блоке `song` укажите `"src": "./assets/audio/song.mp3"`.
3. Замените название, подпись и при желании добавьте строки в массив `lyrics`.
4. Поставьте `"published": true`.

Воспроизведение запускается нажатием, чтобы работать с ограничениями iPhone. Пластинка вращается только во время воспроизведения. Есть пауза, перемотка, длительность и доступные подписи элементов управления.

## Фотографии и видео

Положите файлы в `assets/photos/` и `assets/videos/`, заполните `items` в блоке `memories`, затем поставьте `published: true`:

```json
[
  {
    "type": "photo",
    "src": "./assets/photos/walk.jpg",
    "alt": "Фотография с нашей прогулки",
    "caption": "Тот самый вечер"
  },
  {
    "type": "video",
    "src": "./assets/videos/day.mp4",
    "poster": "./assets/photos/day-cover.jpg",
    "caption": "Наш маленький фильм"
  }
]
```

Поле `poster` необязательно. Рекомендуемые форматы: JPEG/WebP, MP4 (H.264 + AAC). Фото открываются в увеличении, видео имеют обычные элементы управления и `playsinline` для iPhone. Изображения загружаются лениво, видео — только с метаданными.

## Добавить ещё один виджет

Добавьте объект в `moments` с уникальным `id`. Можно создать сколько угодно писем, песен и галерей. Ссылка формируется автоматически. Новый вид оформления реализуется отдельной функцией в `app.js` и стилями в `styles.css`.

## Ещё кое-что

Блок `surprise` открывает игровое окно по относительному адресу `./game/`. В предпросмотре `?preview=all` ссылка видна сразу; обычное открытие настроено на полночь 13 ноября вместе с письмом. Время и публикация меняются в `content.json`.

На экране нет заголовка, обложки и названия: загрузка начинается при переходе с главной. Игра запускается автоматически. Если браузер ждёт разрешения на звук, внутри окна появляется значок ▶; нажатие продолжает запуск со звуком. Этот же значок снимает паузу после возвращения из другой вкладки.

Все файлы находятся в `game/`. Внешний игровой сайт и ссылки на localhost для запуска не нужны. Первая загрузка составляет около 153 МиБ; в это время показывается нейтральный индикатор. Для игры нужны клавиатура и мышь. Настройки и сохранения остаются в браузере. Игровому окну нужен HTTP/HTTPS, в том числе при локальном запуске.

Сохранены все девять уровней, оригинальные исполняемый файл, графика и звуковой банк. Для скорости обычный запуск использует пакет без видеозаставок. Полный прежний пакет остаётся в `game/assets/game/` для совместимости и восстановления; новый запуск его не скачивает.

Используется Boxedwine с JIT для WebAssembly, Wine 6 и SIMD. Картинка выводится с ограничением до 30 кадров/с, без увеличения окна сверх 800×600. Звук 22050 Гц идёт через AudioWorklet в отдельном потоке: фиксированный буфер 100 мс, запас 70 мс, начальное заполнение 70 мс. Небольшая дополнительная задержка звука выбрана ради непрерывной музыки. На GitHub Pages изоляцию для аудиопотока включает локальный `game/coi-worker.js`, без серверных настроек. На HTTP и в браузере без общей памяти звук передаётся системному микшеру через заранее запланированные AudioBufferSourceNode, без ScriptProcessor: короткие задержки страницы не прерывают уже поставленные в очередь фрагменты. Если Web Audio недоступен, остаётся совместимый SDL-вывод. Старые сохранения BrowserFS импортируются при первом запуске; новые сохраняются через IDBFS.

Нужен современный браузер: Chrome/Edge 137+, Firefox 131+, Safari 18.4+. Конфигурация, лицензии и полный соответствующий исходный код движка — в `game/runtime/SOURCE.md`. Для локальной диагностики добавить `diagnostics=1` к адресу игрового окна: частота кадров и состояние аудиобуфера будут доступны в скрытом элементе `#diagnostics`, без подписей на странице. Лицензии компонентов находятся в `game/runtime/`; права на игровые материалы принадлежат их правообладателям.

## Проверки и публикация

```sh
npm test
npm run check
git add .
git commit -m "Update content"
git push
```

GitHub Pages публикует `main`, корень репозитория. Публикация занимает некоторое время; на главной затем появится обновлённый контент.

## Сохранить на память

```sh
npm run archive
```

Будет создана папка `exports/tanya23/` с автономным `index.html`, копией медиа и папкой игрового окна. HTML содержит стили, код и контент внутри себя. Письмо, песня и галерея работают при прямом открытии файла; игровому окну нужен локальный HTTP-сервер или обычный сайт; все опубликованные блоки откроются после даты праздника. Предпросмотр всех блоков: добавить `?preview=all` к адресу файла. Сохраните всю папку или упакуйте её в ZIP. Новую копию нужно экспортировать после добавления окончательных материалов.

## Публичность

Репозиторий и сайт общедоступны. Время открытия на статическом сайте скрывает блоки в интерфейсе, но не защищает исходники и заранее загруженные файлы. `noindex` — просьба к поисковым системам, а не контроль доступа. Загружайте только материалы, которые готовы разместить публично. Личные медиа в исходный шаблон не включены. Нет аналитики, внешних шрифтов и фоновой загрузки аудио на главной. Библиотеки игрового окна хранятся в репозитории и загружаются при переходе в него.
