# Первый запуск на бесплатном хостинге

Приоритет — первое открытие игры, когда браузер ещё ничего не сохранил. Страница остаётся на GitHub Pages; платные сервисы не используются.

## Обязательные данные

| Данные | Раньше | Теперь |
| --- | ---: | ---: |
| Wine | 37 247 698 байт | 23 444 156 байт |
| Игра и звук | 117 419 821 байт | 33 159 402 байта |
| Движок WebAssembly | 4 331 137 байт | 1 176 140 байт |
| Всего основных файлов | 158 998 656 байт | 57 779 698 байт |

Сокращение — 63,7%. Дополнительно загружаются небольшие HTML, JS и манифесты. Числа относятся к файлам, а не к повторному запуску из кеша. На локальном сервере готовое меню появилось примерно за 4,5 секунды; скорость первого запуска через интернет зависит от сети и устройства.

- В `SOUNDS.RES` почти 97 МБ несжатого PCM. Девять разных музыкальных дорожек теперь передаются в AAC 48 кбит/с, стерео. Браузер восстанавливает их в исходный формат до запуска игры. Звуковые эффекты и таблица банка сохранены побайтно; музыка сжата с потерями.
- Все девять уровней, графика, задания и оригинальный `NP.EXE` сохранены. Видеозаставки уже отсутствовали в предыдущем быстром пакете.
- Wine содержит использованные при запуске файлы, необходимые ссылки, настройки, шрифты и русские кодировки. Бинарные файлы Wine не изменены. Список — `tools/game-wine-files.json`.
- WebAssembly передаётся в gzip, затем проверяется и компилируется параллельно с загрузкой остальных данных. Сам движок не изменён.
- Первый визит больше не перезагружает страницу ради AudioWorklet: сначала работает заранее запланированный Web Audio, а изоляция устанавливается для следующих переходов.
- При сетевом обрыве файл автоматически дочитывается с последнего байта через HTTP Range, до трёх попыток. SHA-256 проверяется после полной загрузки; проценты обновляются по мере получения данных.
- Сгенерированный звуковой банк живёт в памяти, а не сохраняется как 97-МБ файл в хранилище сохранений.

## Почему не загружать уровни позже

В игре обычное синхронное чтение файлов. Подгрузка по запросу потребует изменения файловой системы эмулятора и может останавливать игру во время чтения уровня. Сейчас все уровни готовы к моменту старта. [Документация файловой системы Emscripten](https://emscripten.org/docs/api_reference/Filesystem-API.html).

## Облако и мгновенный старт

GitHub Pages уже раздаёт файлы из облака. Перенос архива в другое хранилище сам по себе не устраняет передачу этих данных посетителю. Для полного первого скачивания даже при идеальных 20 Мбит/с требуется не менее 23 секунд только на 57,8 МБ, при 100 Мбит/с — 4,6 секунды; к этому добавляется подготовка игры.

Запуск игры на постоянно готовом сервере и передача видео через WebRTC убрали бы большой игровой архив из браузера, но потребовали бы постоянного интернета, добавили задержку управления и оплату работающего сервера. Пользователь выбрал бесплатный хостинг. [Описание облачного стриминга AWS](https://aws.amazon.com/gamelift/streams/faqs/), [условия оплаты готовых серверов](https://aws.amazon.com/gamelift/streams/pricing/).

## Восстановление пакета

На macOS с Python 3 и встроенным `afconvert`:

```sh
python3 tools/package-firstload.py --source . --output game/assets/first-v3 --wine-files tools/game-wine-files.json
```

Исходные архивы остаются в репозитории. AAC может немного отличаться между версиями системного кодировщика; скрипт заново создаёт размеры и SHA-256. Формат банка проверен по [описанию K-D Lab RES](https://aluigi.altervista.org/bms/kdlab_res.bms).

## Окно

Возврат на главную сохраняет режим предпросмотра. Полноэкранная кнопка использует [Fullscreen API](https://developer.mozilla.org/en-US/docs/Web/API/Element/requestFullscreen); при запрете браузером разворачивает окно внутри страницы. Буфер изображения остаётся 800×600 в обоих режимах: увеличивается только отображение.
